# 排版设计规范（Layout Guide）

> 用途：写码前产出**设计契约**，交付前过 **14 条排版自查**。正面数字规则来自实战校准，负面清单移植自 GitHub 高星设计 skill（anthropics/skills · frontend-design、addyosmani/agent-skills、impeccable-lite）。
> 适用所有本 skill 产出的页面；与 recipes.md（组件配方）、theme-backgrounds.md（背景）、pitfalls.md（红线）配合使用。

## 1. 设计契约（写码前 4 行，强制）

任何页面动手前，先产出并展示给用户这份契约：

```text
① 色板：4~6 个命名 hex（底色 / 面板 / 主色 / 强调色 / 状态色）
② 字体：家族与角色（≤2 个家族；数字场景声明 font-mono + tabular-nums）
③ 布局：一句话骨架 + ASCII 线框（对齐方式写明：居中 or 左对齐）
④ 焦点：本页"大胆只用在一处"的那个元素是什么
```

自查：**这方案换成任意同类页面是否也会一样？** 是 → 它是模板，改掉再动手。

## 2. 页面骨架配方（垂直 × 水平）

> **内容体积校验（v1.7.0）**：骨架高度不再是单点比例 —— 一律为**区间 + 触发条件**，按真实内容量取值；内容 ≥ 预估时取区间上限，宁多勿截断。

| 页面类型 | 垂直骨架（区间 + 触发条件） | 水平栅格 | 要点 |
|---|---|---|---|
| **大屏看板** | 顶栏 8~10% / 主区 ~80% / 通知带 6%（单屏零滚动，不适用区间制） | 三列 **22 : 52 : 26**（@1080p ≈ 280px : 1fr : 300px） | 一屏卡片 5~9；每列 2~3 个 Panel |
| **Landing** | Hero **50~70vh** —— 标题 ≤2 行 + 单 CTA 取 55~60vh；标题 ≥3 行或含 3D 主视觉（Lanyard/FluidGlass 等）触发 65~70vh；首屏下方还有 ≥2 个内容区块时压缩到 ≤60vh | 12 栏，内容 max-w-6xl 居中 | Hero 焦点 1 个；区块间距 80~120px |
| **资讯 / 博客** | 头图 **30~45vh** —— 纯文字列表流触发 30~35vh；图文卡片带双行摘要取 40~45vh；带轮播头图取 45vh 封顶 | 卡片 lg 3 栏 / md 2 栏 / sm 1 栏 | 卡片图高固定（如 h-44）保齐平 |
| **作品集** | 头部 **40~70vh** —— 仅名字 + 一句话签名取 40~45vh；含 2 行以上简介/代表作摘要时 ≥56vh（1080p 实测 600px，约 56vh）；含主视觉动效（Lanyard/DecryptedText 大字）触发 60~70vh | Masonry 自适应 | 图 : 文 ≈ 7 : 3 |

## 3. 数字化规律

| 规律 | 数值 | 应用 |
|---|---|---|
| 黄金比例 | 1.618 : 1 | 主内容 : 侧栏宽度；Hero 标题块 : 留白 |
| 三分法 | 1/3 交点 | 焦点元素落位（标题/主视觉/数据大数） |
| 60-30-10 色彩 | 60% 底色 / 30% 面板 / 10% 强调 | 全局配色与状态色预算 |
| 8pt 间距系统 | 4 / 8 / 12 / 16 / 24 / 32 / 48 | **所有 gap / padding 只取该档位**；禁止 13px、2.3rem 式发明值 |
| 字阶 1.25 倍率 | 12 / 15 / 19 / 24 / 30 / 38 | 每屏字阶层级 ≤ 4 档；数字用 font-mono + tabular-nums |
| 信息密度 | 一屏卡片 5~9 个；焦点 ≤ 1 | 超出拆分区或做分屏轮播 |
| 行长控制 | 正文 ≤ 80 字符/行（中文 ≈ 40 字） | 阅读区 max-w-prose |
| 对比度 | 正文 4.5:1 / 大字 3:1 | WCAG AA 底线 |

## 4. 间距与层级细则

- 标题**上松下紧**：标题上方留白 > 下方留白
- **组内紧、组间松**：相关元素紧凑成组，无关区块大方留白分隔
- 标题层级 **h1 → h2 → h3 不跳级**；h1 每页仅一个；标题样式不用于非标题内容
- 优先构图与对齐，**卡片仅用于真有分组边界收益时**；禁止反射式嵌套卡片
- 响应式**改结构而非等比缩放**：收导航 / 重排序 / 改栅格列数

## 5. 反 AI 模板黑名单（交付自查，9 条）

| # | "AI 味"特征 | 生产级做法 |
|---|---|---|
| 1 | 标题中单个词变色/斜体强调 | 强调整块信息，不做字内装饰 |
| 2 | 全大写小标签（eyebrow）挂每个标题 | 标签承载真实信息才出现 |
| 3 | 无意义的 01/02/03 序号装饰 | 内容真是序列/流程才编号 |
| 4 | 万物皆卡片：同圆角、同阴影、同尺寸网格 | 层级用排版与留白表达，卡片留给真分组 |
| 5 | `A · B · C` 中点串元信息 / `WORD — fragment` 标签 | 元信息语义分组（分行或表格） |
| 6 | 每个卡片一个 hover 渐显进场 | 一次编排式页面进场；动效回应"人的动作" |
| 7 | 紫色泛滥 / 渐变过度 / 阴影堆叠 | 语义色 token；阴影 ≤ 1 层 |
| 8 | Lorem ipsum 式占位文 | 真实感的中文示例内容 |
| 9 | 大胆到处撒（处处是重点） | **大胆只用在一处**，其余克制 |

## 6. 排版自查清单（交付前 14 条全过）

1. 垂直骨架比例符合页面配方（±5%）
2. 栅格列宽按配方；同排卡片等高/等宽
3. 间距全部落在 8pt 档位（无发明值）
4. 字阶层级 ≤ 4 档；数字用 font-mono + tabular-nums
5. 一屏卡片 5~9；焦点元素 ≤ 1 且落在三分点
6. 色彩占比约 60-30-10；状态色未超预算
7. 1920×1080 与 1366×768 双档下单屏完整、无溢出滚动条（看板类）
8. 中英文混排行高、截断（line-clamp）统一
9. 无黑名单 #1~3（标题装饰类）
10. 无黑名单 #4~5（卡片滥用 / 中点串）
11. 标题层级不跳级；h1 唯一
12. 标题上松下紧；组内紧组间松
13. 正文行长 ≤ 80 字符
14. 进场动效为一次编排式，无散点 fade-up
